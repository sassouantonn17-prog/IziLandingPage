# LivrExpress — Landing Page Haute-Fidélité à Dakar

LivrExpress est une landing page moderne, cinématographique et ultra-lisible pour un service de livraison express et sécurisée de colis en moins de 2 heures à Dakar.

## 🚀 Fonctionnalités & Système de Design

- **Hero Cinématographique :** Photo réelle de coursier en scooter à Dakar, avec typographie moderne et contrastes optimisés.
- **Suivi Télémétrique en Temps Réel :** Carte de suivi des courses actives dans Dakar avec transition élastique automatique.
- **Mises à Jour SMS / WhatsApp en Direct :** Émulateur de flux d'informations direct tapé en temps réel.
- **Planificateur de Créneaux :** Grille hebdomadaire avec curseur interactif animé.
- **Le Manifeste :** Section philosophie valorisant le gain de temps et la sécurité.
- **Protocole en 3 Étapes :** Étapes interactives avec animations vectorielles SVG dédiées (engrenages, radar de balayage, onde de vitesse).
- **Tarifs Clairs & Transparents :** 1 Course Express (15.000 FCFA), Pack 10 Livraisons (120.000 FCFA), Livreur Dédié (450.000 FCFA).
- **Modal de Commande Interactive :** Formulaire de réservation rapide avec sélection des quartiers dakarois (Plateau, Almadies, Point E, Ngor, Mermoz, etc.) et confirmation instantanée avec code de suivi.

## 🛠️ Stack Technique

- **Framework :** React 19 + Vite
- **Styles :** Tailwind CSS v3.4.17 + Vanilla CSS
- **Animations :** GSAP 3 (ScrollTrigger)
- **Icônes :** Lucide React
- **Typographie :** Plus Jakarta Sans, Inter, JetBrains Mono

## 💻 Démarrage Local

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour la production
npm run build
```
